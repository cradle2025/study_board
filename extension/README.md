# StudyBoard 资料收件箱 · 浏览器扩展

一个只有几十行代码的下载改写器：凡是下载 **PDF / PPT / Word / Excel**，
自动把保存位置改到「下载目录 / **StudyBoard收件箱** /」——学习看板监控这个目录，
发现新文件会弹一次归属选择，点一下课程就完成入库与改名。你不再需要手动搬文件。

不采集任何数据、不上传任何内容，只是本地事件改写器。

## 安装（开发者模式）

商店上架前，先用开发者模式加载：

1. 打开浏览器的扩展管理页：
   - Chrome：地址栏输入 `chrome://extensions`
   - Edge：地址栏输入 `edge://extensions`
2. 右上角打开「**开发者模式**」
3. 点「**加载已解压的扩展程序**」，选择本目录（`extension/`）
4. 完成。之后在学校网站点下载，资料类文件会自动进收件箱

## 工作方式

```
你在学校网站点下载
        │
        ▼
扩展判断：是资料类文件吗？（按扩展名 pdf/ppt/pptx/doc/docx/xls/xlsx）
        │ 是
        ▼
改存到  下载目录/StudyBoard收件箱/干净文件名
        │
        ▼
学习看板监控到新文件 → 弹一次「归属哪门课？」→ 自动复制入库并按课程改名
```

- 普通下载（网页、图片、安装包）不受影响
- 收件箱里的文件导入成功后会**移入系统回收站**（可恢复），不会堆积
- 学习看板没有运行时，文件只是安静地躺在收件箱里，下次打开看板时会补弹归属选择

## 与主进程的约定

目录名 `StudyBoard收件箱` 与文件名清洗规则定义在主进程的
`src/shared/materials.ts`（`MATERIAL_INBOX_DIRNAME`），两边必须保持一致；
如果学习看板的设置里改过收件箱路径（设置 → 课程资料），扩展无需改动——
扩展只负责「默认下载目录下的子路径」，完整路径由看板侧配置。
